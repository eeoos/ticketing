# US-04 모의 결제로 예매 확정

**사용자로서** 잡아 둔 좌석을 결제해 예매를 확정하고 싶다. **그래서** 좌석이 내 것이 된다.

## 인수 조건
1. **Given** 사용자 A가 홀드한 좌석이 만료 전일 때
   **When** 사용자 A가 모의 결제로 예매를 확정하면
   **Then** 성공하고, 좌석은 `SOLD`가 되며, 응답에 예매 식별자와 좌석·사용자 정보가 포함된다.
2. **Given** 사용자 A가 홀드한 좌석이 만료 전일 때
   **When** 사용자 B가 그 좌석의 예매를 확정하면
   **Then** "본인 홀드 아님" 오류로 거절되고, 좌석은 계속 A의 `HELD`다.
3. **Given** 사용자 A의 홀드가 만료되었을 때
   **When** 사용자 A가 예매를 확정하면
   **Then** "홀드 만료" 오류로 거절되고, 좌석은 `SOLD`가 되지 않는다(조회 시 `AVAILABLE`).
4. **Given** 홀드되지 않은 `AVAILABLE` 좌석일 때
   **When** 누구든 예매를 확정하면
   **Then** "홀드 없음" 오류로 거절되고, 좌석은 `AVAILABLE`로 남는다.
5. **Given** 이미 `SOLD`인 좌석일 때
   **When** 누구든(구매자 본인 포함) 다시 예매를 확정하면
   **Then** "이미 판매된 좌석" 오류로 거절되고, 예매는 하나만 남는다.
6. **Given** `SOLD`가 된 좌석이 있을 때
   **When** 5분 이상 지난 뒤 다른 사용자가 홀드하면
   **Then** 거절된다(`SOLD`는 만료되지 않는다).
7. **Given** `X-User-Id` 헤더가 없을 때
   **When** 예매를 확정하면
   **Then** "사용자 식별 필요" 오류로 거절되고, 좌석 상태는 바뀌지 않는다.
