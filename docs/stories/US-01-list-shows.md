# US-01 공연 목록 보기

**사용자로서** 예매 가능한 공연 목록을 보고 싶다. **그래서** 볼 공연을 고를 수 있다.

## 인수 조건
1. **Given** 공연이 여러 개 등록되어 있을 때
   **When** 공연 목록을 요청하면
   **Then** 모든 공연이 각각 식별자, 제목, 장소, 시작 시각과 함께 반환된다.
2. **Given** 등록된 공연이 없을 때
   **When** 공연 목록을 요청하면
   **Then** 오류 없이 빈 목록이 반환된다.
3. **Given** `X-User-Id` 헤더가 없을 때
   **When** 공연 목록을 요청하면
   **Then** 헤더가 있을 때와 같은 목록이 반환된다.
