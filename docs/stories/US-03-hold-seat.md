# US-03 좌석 하나를 5분 동안 잡기

**사용자로서** 고른 좌석 하나를 잠시 잡아 두고 싶다. **그래서** 결제하는 동안 다른 사람이 가져가지 못한다.

## 인수 조건
1. **Given** `AVAILABLE` 좌석이 있을 때
   **When** 사용자 A가 `X-User-Id: A`로 그 좌석을 홀드하면
   **Then** 성공하고, 좌석은 `HELD`가 되며, 응답에 홀드 만료 시각(홀드 시각 + 5분)이 포함된다.
2. **Given** 사용자 A가 홀드한 좌석이 만료 전일 때
   **When** 사용자 B가 그 좌석을 홀드하면
   **Then** "이미 잡힌 좌석" 오류로 거절되고, 좌석은 계속 A의 `HELD`다.
3. **Given** 사용자 A가 홀드한 좌석이 만료 전일 때
   **When** 사용자 A가 같은 좌석을 다시 홀드하면
   **Then** 거절되고, 기존 홀드의 만료 시각은 바뀌지 않는다.
4. **Given** 사용자 A의 홀드가 만료되었을 때(5분 경과)
   **When** 사용자 B가 그 좌석을 홀드하면
   **Then** 성공하고, 좌석은 B의 `HELD`가 되며 새 만료 시각을 받는다.
5. **Given** `SOLD` 좌석이 있을 때
   **When** 누구든 그 좌석을 홀드하면
   **Then** "이미 판매된 좌석" 오류로 거절되고, 좌석은 `SOLD`로 남는다.
6. **Given** `AVAILABLE` 좌석이 있을 때
   **When** 두 사용자가 동시에 그 좌석을 홀드하면
   **Then** 정확히 한 요청만 성공하고 다른 요청은 "이미 잡힌 좌석" 오류로 거절된다.
7. **Given** `X-User-Id` 헤더가 없을 때
   **When** 좌석을 홀드하면
   **Then** "사용자 식별 필요" 오류로 거절되고, 좌석 상태는 바뀌지 않는다.
8. **Given** 존재하지 않는 좌석 식별자로
   **When** 홀드하면
   **Then** "찾을 수 없음" 오류가 반환된다.
